# Audit examples

Synthetic inputs for `quant-trade audit run`, generated by `tests/audit_fixtures.py`
(`positive_drift(1500, seed=3)` and `trades_frame(60, seed=9)`). They are random
walks with a built-in drift, not market data, and they exist so the runbook has
something to point at:

```
quant-trade audit run --equity examples/audit/sample_equity.csv \
  --trades examples/audit/sample_trades.csv --trials 20 --cost-bps 5 \
  --oos-start 2023-01-01 --output-dir outputs/audit_demo
```
